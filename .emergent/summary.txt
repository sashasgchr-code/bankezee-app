<analysis>**original_problem_statement:**
Build a full-stack web application for a fintech company called Bankezee. The platform should function as a Lead Generation + Sales CRM + Partner Management system.

**PRODUCT REQUIREMENTS:**
- **User Roles:** Admin, Operations Team, Sales Agents, Freelance/Retail Partners.
- **Core Modules:**
    - **User Management:** Role-based sign-up, login, and dashboards. Admin can create Ops accounts, view all users, and delete users.
    - **Lead Generation:** Public, Agent, and Partner lead forms.
    - **QR Code System:** Unique QR codes for Agents/Partners to tag leads.
    - **CRM:** Full lead management system with status tracking, lead assignment, bulk assignment, and lead deletion.
    - **Eligibility Tracking:** Operations team can track a lead's eligibility with multiple banks.
    - **Dashboards:** Role-specific dashboards with advanced analytics, filtering, and lead lists.
    - **Commission Tracking:** System to calculate and display agent/partner payouts.
    - **Document Upload:** A system for uploading and associating documents with leads. Agent/Partner ID cards should be viewable by Admin.
    - **Notes:** A feature for Ops/Admin to add notes to a lead.
    - **Lead Export:** Admin can download lead data in CSV format.
- **Tech & UI:**
    - Modern, responsive UI with a Green + Gray color palette.
    - FastAPI backend, React frontend, MongoDB database.
    - Secure JWT-based authentication (Email/Password).

**User's preferred language**: English

**what currently exists?**
A comprehensive full-stack CRM application featuring role-based access (Admin, Operations, Agent, Partner). The application supports the full lead lifecycle, from creation to status tracking. Key features include:
